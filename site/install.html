Installation / 安装

Install / 安装

1. Clone The Repository / 克隆仓库

git clone https://github.com/Zw-awa/PulseAxis.git
cd PulseAxis

2. Suggested Reading Order / 建议阅读顺序

  1. Read the root README first. / 先读根目录 README。
  2. Then read `firmware/`, `hardware/`, or `software/` based on your interest. / 再根据兴趣阅读 `firmware/`、`hardware/` 或 `software/`。
  3. Read contribution and support docs when you want to collaborate. / 准备协作时再阅读贡献和支持文档。

3. Current Stage / 当前阶段

The project is still in planning and early public bootstrap. At this stage, the main goal is to understand the repository structure and follow the project as it evolves. 项目仍处于规划和公开初始化阶段。当前最重要的是理解仓库结构，并跟踪项目后续演进。
