Troubleshooting / 问题指南

Use this page to decide where to ask questions, report issues, or raise safety-sensitive concerns. 使用此页判断该去哪里提问、报错或反馈敏感问题。

Choose The Right Path / 选择正确路径

  • Use SUPPORT for general questions. / 一般问题先看 SUPPORT。
  • Open a Bug Report for broken docs, links, or reproducible repository issues. / 文档、链接或仓库可复现问题请提 Bug Report。
  • Open a Feature Request for scoped improvements. / 范围明确的改进建议请提 Feature Request。
  • Use SECURITY for security-sensitive issues. / 安全相关问题请看 SECURITY。
