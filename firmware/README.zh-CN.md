# 固件

[English](./README.md) | [简体中文](./README.zh-CN.md) | [繁體中文](./README.zh-TW.md)

这个目录将用于承载 PulseAxis 的嵌入式控制侧内容。

面向公开的预期职责包括：

- 开发板 Bring-up 说明
- 电机控制运行时结构
- 与 `FOC` 相关的控制实现
- 位置环与运动执行接口
- 诊断与安全停机行为
- 适合公开发布的测试与调参说明

## 当前状态

在当前仓库阶段，这个目录仍然是公开占位目录。
它的作用是在代码加入之前，先把固件工作流的边界明确出来。

## 计划中的公开内容

随着项目推进，这个目录未来可能包含：

- 源代码
- 板级支持结构
- 接口定义
- 面向公开的配置示例
- 台架测试记录
- 调参与排障指南

## 备注

- 并不是所有本地设计笔记都应立即放到这里。
- 公开固件文档应保持稳定、可阅读。
- 粗糙的私有规划笔记应放在公开树之外。
