# 韌體

[English](./README.md) | [简体中文](./README.zh-CN.md) | [繁體中文](./README.zh-TW.md)

這個目錄將用於承載 PulseAxis 的嵌入式控制側內容。

面向公開的預期職責包括：

- 開發板 Bring-up 說明
- 電機控制執行期結構
- 與 `FOC` 相關的控制實作
- 位置環與運動執行介面
- 診斷與安全停機行為
- 適合公開發布的測試與調參說明

## 目前狀態

在目前倉庫階段，這個目錄仍然是公開占位目錄。
它的作用是在程式碼加入之前，先把韌體工作流的邊界明確出來。

## 計畫中的公開內容

隨著專案推進，這個目錄未來可能包含：

- 原始碼
- 板級支援結構
- 介面定義
- 面向公開的設定範例
- 台架測試記錄
- 調參與排障指引

## 備註

- 並不是所有本地設計筆記都應立即放到這裡。
- 公開韌體文件應保持穩定、可閱讀。
- 粗糙的私有規劃筆記應放在公開樹之外。
