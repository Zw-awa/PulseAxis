# 軟體

[English](./README.md) | [简体中文](./README.zh-CN.md) | [繁體中文](./README.zh-TW.md)

這個目錄將用於承載 PulseAxis 的主機側工具與非韌體支援程式碼。

未來面向公開的職責可能包括：

- 串口或 CAN 除錯工具
- 日誌採集輔助腳本
- 簡單視覺化工具
- 參數匯入匯出輔助工具
- 降低 Bring-up 成本的腳本

## 目前狀態

與倉庫結構、公開文件和嵌入式控制主線相比，這不是第一階段的重點。
現在先建立這個目錄，是為了給未來工具鏈預留一個清楚的公開歸屬。

## 公開方向

如果早期階段要加入工具鏈內容，優先考慮：

- 聚焦的命令列工具
- 清楚的文字或檔案輸出
- 能幫助解釋或驗證工作流的腳本

在此之前，不急於做更重的桌面軟體。
