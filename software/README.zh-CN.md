# 软件

[English](./README.md) | [简体中文](./README.zh-CN.md) | [繁體中文](./README.zh-TW.md)

这个目录将用于承载 PulseAxis 的主机侧工具和非固件支持代码。

未来面向公开的职责可能包括：

- 串口或 CAN 调试工具
- 日志采集辅助脚本
- 简单可视化工具
- 参数导入导出辅助工具
- 降低 Bring-up 成本的脚本

## 当前状态

与仓库结构、公开文档和嵌入式控制主线相比，这不是第一阶段的重点。
现在先建立这个目录，是为了给未来工具链预留一个清晰的公开归属。

## 公开方向

如果早期阶段要加入工具链内容，优先考虑：

- 聚焦的命令行工具
- 清晰的文本或文件输出
- 能帮助解释或验证工作流的脚本

在此之前，不急于做更重的桌面软件。
