# 硬體

[English](./README.md) | [简体中文](./README.zh-CN.md) | [繁體中文](./README.zh-TW.md)

當硬體材料適合公開時，這個目錄將用於承載 PulseAxis 面向公開的硬體部分。

未來可能公開的內容包括：

- 參考 BOM 說明
- 執行機構側介面約束
- 編碼器與驅動器需求
- 包裝或安裝約束
- 達到發布品質後的公開組裝說明

## 目前狀態

專案在第一階段不會公開詳細硬體設計檔。
這個目錄目前的作用是明確公開硬體範圍，而不是暗示已經有完整可發布版本。

## 公開邊界

只要硬體資訊已經穩定、並且對協作者有幫助，就可以發布在這裡。
不穩定的私有筆記、被否決的方案和粗糙的選型草稿，應繼續保留在公開樹之外，直到能被清楚重寫為止。
