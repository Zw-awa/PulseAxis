# Hardware

[English](./README.md) | [简体中文](./README.zh-CN.md) | [繁體中文](./README.zh-TW.md)

This directory will hold the public hardware-facing side of PulseAxis when hardware material is ready to be shared.

Potential public content may include:

- reference BOM notes
- actuator-side interface constraints
- encoder and driver requirements
- packaging or mounting constraints
- public assembly guidance when release quality is sufficient

## Current State

The project is not publishing detailed hardware design files in the first public phase.
This directory currently exists to define the public hardware scope, not to imply a finished release.

## Public Release Boundary

Hardware information that is stable and useful to collaborators can be published here.
