# 硬件

[English](./README.md) | [简体中文](./README.zh-CN.md) | [繁體中文](./README.zh-TW.md)

当硬件材料适合公开时，这个目录将用于承载 PulseAxis 面向公开的硬件部分。

未来可能公开的内容包括：

- 参考 BOM 说明
- 执行机构侧接口约束
- 编码器与驱动器需求
- 包装或安装约束
- 达到发布质量后的公开装配说明

## 当前状态

项目在第一阶段不会公开详细硬件设计文件。
这个目录当前的作用是明确公开硬件范围，而不是暗示已经有完整可发布版本。

## 公开边界

只要硬件信息已经稳定、并且对协作者有帮助，就可以发布在这里。
不稳定的私有笔记、被否决的方案和粗糙的选型草稿，应继续保留在公开树之外，直到能被清晰重写为止。
